Bilbiotecas Necessárias:
1. Opencv
2. Dlib (https://github.com/z-mahmud22/Dlib_Windows_Python3.x/tree/main)
3. Numpy
4. CMake
5. face-recognition

Instalar PIP:
```sh
python -m ensurepip --upgrade
py get-pip.py
```
Instalar Dlib (escolha de acordo com sua versão do python):
```sh
python --version 
python -m pip install dlib-xxx.whl
```
Instalar Opencv:
```sh
python -m ensurepip --upgrade
python -m pip install opencv-python
```
Instalar cmake:
```sh
python -m pip install cmake
```
Instalar Face Recognition:
```sh
python -m pip install face_recognition
```

Arquivo necessário:
https://github.com/italojs/facial-landmarks-recognition/blob/master/shape_predictor_68_face_landmarks.dat
